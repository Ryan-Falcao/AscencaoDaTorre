# Fontes da interface

Alice Regular: títulos, com serifas coerentes com a arte de fantasia e papel.
Alegreya Sans Medium: menus, diálogos, números e instruções.

As fontes são distribuídas com o jogo; não precisam estar instaladas no computador. Licenças SIL Open Font License incluídas nesta pasta.

Fontes oficiais:
- https://github.com/google/fonts/tree/main/ofl/alice
- https://github.com/google/fonts/tree/main/ofl/alegreyasans
